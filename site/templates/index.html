DATEX II v3 · XML and JSON · read · stream · write

European road traffic data, as Rust types.

datex2 reads, streams and writes DATEX II, the European standard for road traffic and travel information. One call turns a national feed, XML or JSON, into typed data. The reader tolerates what real feeds send and tells you what it tolerated; the writer produces only documents the official schemas accept, including AFIR charging data for Germany's Mobilithek.

Four rules it keeps

Road operators, access points and charging operators across Europe publish DATEX II. The standard is large and real feeds bend it. These rules are what makes the data usable anyway.

01

Tolerant in

Namespaces under http://levelC/…, a payload without xsi:type, required elements left out, a decimal comma in a number: the reader accepts the deviations national feeds really have, and reads the rest of the document.

02

Nothing silent

Every deviation is a warning with its kind, the element path and the byte offset. Unknown elements are reported, extension content is kept as it was written, and no value is ever made up.

03

Strict out

The writer checks required content, list sizes and every value rule of the schema. When it succeeds, the official 3.7 schemas, or the Mobilithek profile's, accept the document; when it cannot, it names the place, the rule and the schema type. It never rounds.

04

Safe on untrusted input

Nesting, attributes and token length are bounded while reading, document type declarations are refused, every text in an error is made safe to log, and the reader is fuzzed. There is no unsafe.

No setup

You do not state a version, a namespace, a schema or an envelope. The crate works on the bytes you give it and opens no files or sockets of its own.

  • Any document shape. A payload, a messageContainer with several payloads, a root named after the publication, and SOAP around any of them.
  • Any 3.x release. The types are generated from the official 3.7 schemas and read documents of every 3.x release.
  • Names from the standard. SituationRecord is SituationRecord, so the official documentation applies to the Rust types.
  • Shared fields without matching. record.validity() works for an accident, roadworks and every other kind of situation record.

And what is not

Named, so that you do not have to find out.

DATEX II version 2

This release handles version 3. The version 2 model, which several countries still publish, is not read yet.

Exchange and transport

No HTTP client, no SOAP services, no Exchange 2020 protocol. A messageContainer yields its payloads and its exchange information, such as snapshot or delta, and nothing more.

Older shapes of draft namespaces

Parking, controlled-zone and traffic-regulation documents written against releases before 3.6 lose the elements that 3.7 renamed; each is reported.
